# Debug Lab · Repositorio del grupo

Guía didáctica para aprender a localizar y explicar errores usando el depurador de Visual Studio Code.

## Integrantes

- Argenis L.
- Rubén T.
- Mario G.
- Lucía M.

## Tema asignado

Depuración en Visual Studio Code.

## Contenido de la web

La página explica:

- Qué es la depuración y para qué sirve un depurador.
- Cómo iniciar una sesión con `F5`, `launch` y `attach`.
- El uso de breakpoints y la ejecución paso a paso.
- La inspección de variables, Watch, Call Stack y Debug Console.
- Un flujo de trabajo para investigar y verificar un error.
- Una demostración interactiva de un error de índice en JavaScript.
- Un glosario y las fuentes consultadas.
